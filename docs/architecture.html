Request Data Flow

User changes filter→ useFilters() ref updates→ api.js builds query params→ GET /api/* (axios)→ FastAPI apply_filters()→ In-memory list filter→ Pydantic validate→ JSON response→ ref.value = data→ computed() recomputes→ DOM re-renders

Filters: Time Period · Warehouse · Category · Order Status. Value 'all' = skip. Category is case-insensitive; warehouse is case-sensitive.

Key Properties

Stateless

read-only
  • All endpoints are GET. Data loaded once at import; mutations don't persist across restart.

No Database

in-memory
  • JSON files are the source of truth. Regenerate via server/generate_data.py.

Filter-Driven

4 global filters
  • Shared filter state flows through every view via query params; backend filters lists on each request.
